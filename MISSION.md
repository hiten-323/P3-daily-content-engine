# Mission

Build Purity Beans — India's cleanest instant coffee (100% coffee, zero chicory,
no fillers, by Pure Pantry Provisions) — into a trusted consumer brand by running
an autonomous Growth Operating System that:

1. **Grows the audience** from 105 Instagram followers toward 100K+ by publishing
   daily follower-first content engineered for shares, saves, and follows.
2. **Converts attention into revenue** through stage-aware conversion content
   routing to https://p3online.in, measured by Shopify order attribution.
3. **Learns from real outcomes** — every post's engagement and revenue feed back
   into tomorrow's strategy automatically, with zero manual work required.

## What this system is

A closed-loop growth engine: Generate → Publish (at algorithm-optimal times) →
Measure (Instagram insights + Shopify orders) → Learn (viral memory, hashtag
scores, hook performance) → Generate better — daily, unattended, on GitHub Actions.

## What this system is not

- Not a guarantee of virality or follower counts. It maximizes *probability*
  through psychology, retention engineering, and iteration (see POLICY_ENGINE.md,
  Honesty Rule).
- Not a replacement for the founder. Video production from tool briefs, community
  replies, and strategic pivots remain human decisions.

## The single question the system asks every morning

**"What is the fastest way to gain followers tomorrow — and which of yesterday's
content actually made money?"**

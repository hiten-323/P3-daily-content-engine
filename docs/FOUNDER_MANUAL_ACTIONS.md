# Founder Manual Actions — the high-value things the engine CANNOT automate

Extracted from the growth-video reviews. These move the needle but Instagram
only allows them by hand (no API). Do them once (profile) or per-post (music).

## 1. SEO-optimize your Instagram profile (one-time, ~5 min) — HIGH VALUE

Instagram search weights the **Name field** (not @username) and **bio** heavily.
Ranking here gets you found when people search "instant coffee", "no chicory", etc.

**Name field** (Edit Profile → Name — this is the searchable one):
```
Purity Beans | Instant Coffee, No Chicory
```

**Bio** (keyword-rich, benefit-led, one clear CTA):
```
☕ 100% coffee. Zero chicory. Zero fillers.
🇮🇳 India's cleanest instant coffee
📖 We print what's inside — dare you to read any other label
👇 Find your blend
```
**Link:** https://p3online.in  (or a link-in-bio with product + the lead magnets)

**Category:** set to a coffee/food category. **Also:** switch to a Business/Creator
account if not already (unlocks insights the engine reads + shopping tags).

## 2. Add trending audio to every reel — per post — HIGH VALUE

Reels with trending audio get materially more reach. The engine posts the video;
before it goes out (or right after, via edit) pick a trending track in-app.
Silent reels underperform. (The engine leaves reels silent by design — audio
licensing — so this is your 10-second add.)

## 3. Add music to carousels — per post — MEDIUM VALUE

A carousel WITH music becomes eligible for the **Reels feed** = far more reach
(carousels-with-audio get pushed like reels). The Graph API can't attach audio,
so add a trending track in-app when a carousel matters.

## 4. Reply to comments within the first hour — daily — HIGHEST VALUE

The single biggest lever no engine can pull. Early comment velocity signals the
algorithm, and personal founder replies convert followers to buyers far better
than any automation. The value-unlock reels (comment a keyword → get a resource)
only work if you actually reply with the resource. Budget 15 min/evening.

## 5. Produce 1 hero reel/week — weekly — HIGH VALUE

Talking-head / real-footage reels spread; slideshows rarely go viral. Drop your
best one in `hero_videos/` and the engine posts it in the prime 22:00 slot
automatically. Lighting > camera: turn off the room light, use one soft box +
a window. Your phone is enough.
```
Everything else — generation, captions with search queries, hashtags, blog,
LinkedIn, YouTube, timing, learning — the engine already does for you.
```

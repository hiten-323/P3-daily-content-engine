## What was hardened (this cycle)

### Workflow state machine

Canonical slots (source of truth: `content_generator/core/slot_registry.py` + `.github/workflows/daily.yml`):

| Slot | IST | UTC cron | Responsibility |
|------|-----|----------|----------------|
| generate | 06:00 | `30 0 * * *` | Research → generate → gates → creative → non-IG distribution; IG/FB held |
| morning | 10:00 | `30 4 * * *` | Publish IG carousel + FB mirror from persisted content |
| evening | 22:00 | `30 16 * * *` | Publish IG reel + FB mirror from persisted content |

Invariants now enforced:

- Manual runs require an explicit `slot` input — no wall-clock guessing.
- `FORCE_SLOT` is set by cron expression or dispatch input; `slots.get_current_slot()` respects it.
- Generate verifies **persistence** (`output/content_*.json`), not publication.
- Morning/evening verify the **publish contract** (`publish_contract.evaluate`).
- `held` / `skipped` are legitimate green outcomes; `partial` / `missing` fail.
- Meta Graph **v24.0** soft-check on generate; hard preflight on publish slots.
- Git is authoritative persistent state; Actions cache is not used for output state.
- Persist to Git only after slot-result success; artifacts (`always()`) retain diagnostics for failed runs.
- Push/rebase failures fail loudly (no swallowed `git pull ... || true` on the critical path).
- Extended content is owned by `founder_policies.yaml → content.enable_extended_content`, never hardcoded in the workflow env.

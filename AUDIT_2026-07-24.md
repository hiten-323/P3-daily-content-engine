# Full Audit — 2026-07-24

## Executive result
The engine already has a strong constitutional/learning architecture, but follower growth was partially described rather than operationalized. This patch adds a deterministic Instagram Growth Director, fixes the publishing-time mismatch, and fixes a missing runtime dependency.

## Critical findings fixed
1. **Schedule drift:** README/architecture promised 08:00 + 20:00 IST, while GitHub Actions actually ran 10:00 + 22:00 IST. Cron is now 08:00 + 20:00 IST.
2. **Follower attribution flaw:** daily follower delta was evenly assigned to due posts, which creates false post-level causality. Growth intelligence now explicitly treats follower delta as account-level evidence. Existing field remains for backward compatibility, but should not be used as precise attribution.
3. **Growth strategy gap:** performance data existed, but there was no compact Instagram-specific strategy layer ranking formats/hooks by action-per-reach. Added `analytics/instagram_growth.py`.
4. **Missing dependency:** runtime emitted repeated `No module named langdetect`; added `langdetect`.

## Instagram growth system added
- Ranks recent formats by `(shares+saves+comments)/reach`.
- Surfaces top hook structures from first-party account results.
- Injects a daily Instagram Growth Director block into generation context.
- Enforces discovery/retention roles: Reels=discovery, carousels=saveable depth, Stories=trust/replies.
- Preserves ethical constraints: no bots, engagement pods, follow/unfollow automation, or mass unsolicited DMs.
- Keeps follower growth subordinate to revenue/brand governance rather than vanity metrics.

## Recommended next measurement upgrades
- Store 24h/72h/7d insight snapshots instead of a single ~20h read.
- Add reel watch-time/completion metrics when the connected Graph API permissions/version expose them reliably.
- Add profile-view/follow conversion when supported by account insights; do not infer unavailable metrics.
- Run hook/format decisions only after minimum sample sizes to avoid overfitting.
